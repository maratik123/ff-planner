# Subtask 0.1 — Разбить app.rs на модули

## Контекст
`src/app.rs` (~365 строк) содержит всю UI-логику: палитру, инспектор, канвас, кнопки, статистику и состояние. Проверка: `./check.sh`.

## Цель
Разбить на модули без функциональных изменений:
- `src/panels/palette.rs` — `PalettePanel`
- `src/panels/inspector.rs` — `InspectorPanel` (в т.ч. сводка)
- `src/canvas.rs` — канвас (grid/buildings paint, pan/zoom, click/drag обработчики)
- `src/ui.rs` (или `src/panels/mod.rs`) — сборка `eframe::App::ui`

## Ограничения
- Без изменения поведения: те же файлы данных (`data/building_dump.json`), та же сериализация состояния.
- Соблюдать `AGENTS.md`: минимальные `pub`, без лишних комментариев, strict lints.

## Критерии приёмки
- `cargo test --workspace --lib` и `./check.sh` проходят.
- `app.rs` сводится к тонкому `TemplateApp` (стейт + вызовы панелей).
- Новая структура соблюдает правила public API проекта.
