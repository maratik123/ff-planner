# Subtask 2.1 — Аналитическая сводка (ресурсы/труд/рабочие силы)

## Контекст
Stats в инспекторе только по категориям и кол-ву. Нужна сводка из данных зданий.

## Цель
- Суммарный труд (`work_required_to_construct`), суммарные `gold_required_to_relocate`, кол-во builders/workers.
- Материалы: итог по `materials` (и `materials_after_construction`) с приоритетом строящей структуры.
- UI: панель/вторую секцию инспектора с раскрывающимися блоками.

## Ограничения
- Источник честности: `all()` (dump); UI не должен перечитывать JSON.

## Критерии приёмки
- Тесты: арифметика сумм на тестовом лейауте.
- `./check.sh` проходит.
