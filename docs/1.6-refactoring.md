# Subtask 1.6 — Рефакторинг Rust-части

## Контекст
Проведено исследование Rust-части (~3000 строк). Тесты проходят, но найдены проблемы: `canvas.rs` смешивает геометрию и UI, `Layout::occupied_cells`/`can_place_ignoring` пересчитывают набор клеток на каждый вызов, `validate()` и stats пересчитываются каждый кадр (и дублируются между status bar и inspector), мелкие шероховатости (сортировка по `format!`, тихий дефолт при битых сейвах, `first()` вместо последнего выбранного).

## Цель
Улучшить структуру и производительность без изменения поведения; все правки — TDD (тест до реализации).
