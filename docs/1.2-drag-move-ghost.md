# Subtask 1.2 — Drag & drop перемешивания и ghost-превью

## Контекст
Только кликовая установка вплотную; никакого перемещения существующих зданий.

## Цель
- Drag по канвасу существующего здания → ghost-призрак (зелёная зона — допустимо, красная — нет).
- Drop: если допустимо — обновить `pos`, иначе — отмена.
- Rotation через зажатый шифт/клавишу R во время drag.

## Ограничения
- Поведение выбора кликом не должно сломаться; `click` vs `drag` различать по порогу.
- TDD.

## Критерии приёмки
- Тесты: drag/drop обновляет позицию; недопустимый drop не меняет лейаут.
- `./check.sh` проходит.
