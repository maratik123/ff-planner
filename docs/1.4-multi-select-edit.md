# Subtask 1.4 — Множественное выделение и редактирование

## Контекст
Один selected id; удаление через инспектор. Нужно редактирование существующих зданий.

## Цель
- Multi-select: Ctrl/Cmd+click добавляет в selection; Shift+click — интервал (опционально).
- Команды: move selection, rotate selection, delete selection.
- Инспектор: batch-операции при множественном выборе.

## Ограничения
- Опора на 1.1 (undo/redo) — операции новые в history.

## Критерии приёмки
- Тесты: смена состава selection; batch-rotate сохраняет валидность.
- `./check.sh` проходит.

## Статус: done

Реализация: `selected: Vec<u64>` (schema v2, миграция из Option<u64>), Ctrl/Cmd+click — toggle, Shift+click — диапазон layout-order; DragState хранит entries + delta (двигает весь selection); R/Shift+R ротирует selection в drag-режиме; Delete/Backspace — удаление selection; batch ops (Move/Rotate/Delete) идут одним undo-шагом через `Command::Batch`; инспектор показывает batch-view (Rotate/Delete) при >1 здании. Ghost рисуется per-building с общей валидностью; все-или-ничего для rotate.
